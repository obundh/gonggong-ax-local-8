- [x] 목록 위 정렬, 파일 이름·종류·크기·경로·삭제 시각·읽기 상태 표시

프로그램 모드의 자동 저장본과 작업 기록도 보이는 대화상자와 검색 조건으로 연결한다. 채팅은 검색이나 저장이 끝나도 계속 잠기며, 사용자가 대화 끝내기를 누르면 결과를 남기고 모드를 바꿀 수 있다.

삭제 시각은 휴지통 이동 기록과 최종 삭제 기록을 구분한다. 기록이 없을 때 수정일을 삭제일로 사용하지 않는다. 이름이 일치하지 않아도 삭제 후보를 숨기지 않는다. 이름 일치는 내용의 동일성을 보장하지 않는다.

미리보기는 지원되는 구조의 최대 8MiB를 메모리로 읽는다. PDF는 제한적인 텍스트 미리보기이며 원래 페이지 배치를 재현하지 않는다. 검색 중에는 기본 정보를 먼저 표시하고 종료 후 내용을 읽는다. 원시 삭제 후보의 읽기 가능성은 남은 데이터와 할당 상태에 따라 달라진다.

합성 휴지통 및 NTFS 이미지의 실제 IPC·Worker 경로와 모의 장치의 화면 상태 회귀를 구분해 시험한다. 실제 사용자 디스크의 삭제·포맷·SSD 복구 시험은 수행하지 않는다.
