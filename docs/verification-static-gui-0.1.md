# GUI 검증 기록

검증일: 2026-09-12. Windows의 Chrome을 Playwright CLI로 직접 구동했습니다. 검증 대상은 복구 엔진이 연결되지 않은 정적 GUI와 내장 예시 상태입니다.

## 확인한 동작

- 키보드로 안내창 열기/닫기, 첫 위치 선택, 저장장치 선택, 검색 시작, 일시정지와 재개.
- 같은 예시 물리 디스크를 원본과 저장 대상으로 중복 선택하지 못함.
- 검색 진행 중 결과 추가, 중단 동안 진행률 유지, 자동 완료.
- 결과 추가와 검색 완료 중 체크박스·일괄 선택·복구 버튼·필터 초기화 버튼의 포커스 유지.
- 개별 선택/미리보기 선택 이후 일괄 선택 버튼의 문구 일치.
- 검색·종류 필터·검색 조건 없음·필터를 바꾸어도 선택 유지·선택이 없으면 복구 버튼 비활성.
- PDF 형태의 예시 문서, 스프레드시트, 샘플 이미지, 내용 미확인 파일의 미리보기.
- 선택한 파일만 예시 복구 결과에 표시. 정상 검사와 일부 손상을 구분하고 실제 저장이 없음을 표시.
- 검색 결과 없음, 저장장치가 없는 경우의 안내, 연결 끊김 시 중단과 재개.
- 검색 중 처음부터 다시 시작할 때 이전 타이머가 새 화면을 변경하지 않음.
- 정상 흐름의 페이지/콘솔 오류 0건. 해당 흐름의 리소스 요청은 미리보기 서버의 정적 파일만 확인됨.

## 화면 점검

- 실제 스크린샷 확인: 시작, 발견 목록, 문서 미리보기, 복구 완료.
- 1440×960 데스크톱, 768×1024 태블릿, 390×844 및 320×720 좁은 화면 점검.
- 좁은 화면의 페이지 가로 넘침 없음. 320px에서 검색 결과와 스프레드시트 미리보기 확인.
- 200% 글자 확대 시 페이지와 선택 버튼의 가로 넘침 없음. 세로로 긴 대화·결과는 스크롤로 탐색.
- 동작 줄이기 설정에서 버튼 전환 제거 확인. 고대비 모드 스크린샷 생성.
- 실제 스크린리더 낭독과 모든 브라우저 조합은 미검증. 자동화와 스크린샷만으로 WCAG 전체 적합성을 주장하지 않음.

## 실행 확인

- `node --check app.js`, `node --check serve.mjs` 통과.
- 파일 URL로 `index.html`을 열고 브라우저를 오프라인 상태로 전환한 후에도 대화 선택 동작 확인. 실제 GUI 실행에 Node.js가 필요하지 않음.
- JavaScript를 비활성화한 브라우저에서 안내 문구 표시 확인.
- 라이브 디스크 스캔, 실제 파일 복구, 실제 HWP/PDF/Excel 파싱, 복구 성공률은 검증 대상이 아니며 구현되지 않음.

## 재현 자료
