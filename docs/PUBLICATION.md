# 공개 준비 기록

2026-10-02. 기존 개발 폴더에서 별도 저장소로 필요한 앱 소스·문서·시험 코드를 옮기고 공개용 기록을 정리했습니다. 엔진 버전은 0.6.1입니다. Git 기록이 없던 하위 폴더에서 최초 공개 스냅샷을 만들었으며 다른 시리즈의 Git 이력과 미커밋 변경을 가져오지 않았습니다.

## 변경 범위

- README, 현황, 기술 시도·문제, 익명화 증거, 고양이 만화 3장 추가.
- 과거 구현표·평가서에는 당시 기록이라는 배너를 추가. 실패나 보류 기록을 성공으로 바꾸지 않음.
- 개인 사용자 경로/파일명을 문서·시험에서 비식별 처리. 캐시·실제 원본/복구본·후보 목록·모델 가중치·빌드 출력 제외.
- 개발용 실행 스크립트의 특정 PC E: 우선 실행을 제거. GUI 시험의 Playwright는 로컬 설치 또는 RECOVERY_PLAYWRIGHT_MODULE로 선택.
- 앱 런타임과 native 읽기 소스는 기존 검증본과 비교. 공개 자료 정리를 새 복구 알고리즘 버전으로 취급하지 않음.

일부 과거 시험의 E: 비교 자료 의존성은 남아 있습니다. 새 clone 전체 시험 재현, 새 SSD 삭제 시험, 외부 문서 앱 정상 열림을 이번 공개의 성과로 주장하지 않습니다.

## 이번 게시 준비에서 다시 확인한 결과

- 공개 정리본에서 Windows 읽기 도우미 빌드 성공.
- 엔진 회귀 시험 677 통과, 실패 0, Windows 링크 생성 권한 제한으로 2건 건너뜀. 개발 PC의 기존 E: 비교 자료가 있는 환경에서 실행했으므로 완전히 비어 있는 외부 PC의 재현 결과는 아닙니다.
- 첫 실행에서 인수 장부의 공개용 링크 설명과 화면용 생성 데이터가 어긋난 1건을 발견했습니다. 정본 인수 장부를 복원한 뒤 관련 4개와 전체 회귀 시험을 다시 실행해 통과했습니다.
- 앱 런타임 코드의 인수본 일치, 만화 3장 파일, 익명화 집계, 문서의 로컬 링크 및 개인 파일명·자격증명 형태를 점검했습니다. 패턴 점검만으로 모든 개인정보·보안 문제가 없다고 보증하지 않습니다.

## 배포 파일

Windows 파일은 2026-09-27의 0.6.1 바이너리를 유지하며 공개용 문서에서 개인 파일명을 지우고 최신 현황·한계 문서를 함께 넣은 별도 ZIP으로 제공합니다. ZIP 해시는 공개 정리로 바뀌므로 원래 로컬 ZIP의 해시와 혼동하지 않습니다. 런타임 파일의 일치와 공개 ZIP 해시는 게시 검증 기록으로 확인합니다.
