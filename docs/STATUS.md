# 진행상황과 현재 한계

공개 정리일: 2026-10-02. 대상 엔진: 0.6.1. 마지막 실제 SSD 반복 시험: 0.6.0 / 2026-09-27. 이번 공개 정리는 새 SSD 복구 성적이 아닙니다.

## 완료의 뜻

| 지표 | 현재 값 | 의미 |
|---|---:|---|
| 단계별 검토 | 10/10 | 모든 단계에 인수 또는 보류·재개 조건을 부여함 |
| 필수 인수 | 21/54 (38.9%) | 1~9단계의 자체 강화 기준을 지정 범위에서 충족 |
| 필수 보류 | 33개 | 일부 구현·고정 시험이 있어도 전체 기준은 미충족 |
| 조건부 연구 | 0/6 인수 | 10단계 연구 조건·장비·증거 미충족 |

옛 `BUILD_CHECKLIST.md`의 103/103은 당시 기능 구현표입니다. 강화된 인수 장부와 분모가 다르며 현재 제품이 100% 완성됐다는 뜻으로 사용하지 않습니다. 인수율 역시 복구율이나 전문 포렌식 대비 백분율이 아닙니다.

## 단계별 상태

| 단계 | 인수 | 현재 남은 핵심 |
|---|---:|---|
| 1. 실패·오해와 결과 판정 수정 | 6/6 | 인수 범위를 넘는 실제 매체 검증은 계속 필요 |
| 2. 원본 보존·이미지 수집 | 5/6 | 실장치·오류 매체의 충분한 인수 |
| 3. 정답이 있는 시험 환경 | 6/6 | 정답 자료·시험 경로 인수이며 모든 FS 지원 아님 |
| 4. 삭제 흔적 추적·결합 | 0/6 | 재사용된 기록, 이력 유실, 이름·본문의 안전한 결합 |
| 5. 기록 기반 본문 복구 | 2/6 | 다양한 확장·손상 기록과 실제 파일 비교 |
| 6. 정밀 카빙·조각 복구 | 0/6 | 실매체 전체 범위·슬랙 완주, 일반 조각 재조합 |
| 7. 다른 위치의 사본과 흔적 | 0/6 | 백업·자동 저장·바로가기 단서의 충분한 실제 인수 |
| 8. 제품화·안전한 운영 | 1/6 | 다양한 장치, 제한 자원, 중단·오류 운영 인수 |
| 9. 독립 비교·성능 검증 | 1/6 | NTFS와 실제 매체의 넓은 독립 비교 |
| 10. 조건부 심화 연구 | 0/6 | 장비·정답 매체·모델별 접근 근거 필요 |

단계 제목은 쉬운 설명용 요약입니다. 항목별 정의와 판정은 [전체 인수 장부](../FORENSIC_READINESS_CHECKLIST.md)를 따릅니다. 4·6단계 0/6은 코드가 없다는 뜻이 아니라 강화된 전체 인수 항목을 완료하지 못했다는 뜻입니다.

## 실제 SSD에서 확인한 것

같은 SSD에서 같은 소유 파일 5개를 새로 복사·삭제하는 실험을 10회 반복했습니다. 대상 메타데이터 단서 50/50, 본문 저장 21/50, 기준본 크기·SHA-256 일치 12/50입니다. 29건은 저장되지 않았고 9건은 저장됐지만 일치하지 않았습니다.

이것은 일반적인 24% 복구율, 50종 파일 시험, 오래전에 삭제된 파일 시험, 또는 일반 사용자의 GUI 선택 성공률이 아닙니다. 시험 정답은 후보 목록을 고정한 뒤 사후 선택·채점에 사용했으며 검색 입력에는 주입하지 않았습니다. 전체 C: 정밀 카빙과 외부 문서 앱 열림 검증도 이 시험에 포함되지 않았습니다.

## 0.6.1에서 개선한 것

변경되지 않은 합성 디스크 이미지에서 중단 후 재개, 경계 서명 재검사, 이전 추출본의 파일 식별·크기·SHA-256 검증을 추가했습니다. 256MiB 입력을 절반 검사하고 재실행한 작은 고정 실험에서 검색 읽기 합계가 약 33% 줄었습니다. OS 캐시는 비우지 않았습니다. HDD/SSD 실사용 속도·복구율 향상의 증거가 아닙니다.

실제 볼륨에는 재개를 적용하지 않습니다. 원본 이미지 연결은 파일 식별·크기·시간 등 메타데이터 비교이며 매 재개마다 원본 전체 해시를 대조하는 방식이 아닙니다. F31 전체와 총 인수 21/54는 그대로입니다.

## 다음 우선순위

1. 개발에 쓰지 않은 NTFS·손상/확장 기록·조각 문서의 별도 정답 자료로 재현 검증.
2. 실패를 기록 재사용, 읽기 오류, 범위 한도, 형식 미지원, 본문 불일치로 나눠 원인 증거 보강. 모두 TRIM으로 분류하지 않기.
3. 변경이 통제된 같은 입력으로 독립 도구와 비교. 서로 다른 시점의 SSD 시험만으로 버전 우열을 단정하지 않기.
4. 실제 매체 전체 범위·슬랙 완주와 오류/미검사 범위 검증.
5. 외부 문서 프로그램에서 정상 열림·서식·전체 내용 확인, 8GB PC와 다른 장치에서 자원/호환성 인수.
6. 개발 PC 경로에 의존하는 회귀·GUI 시험을 독립 환경에서도 재현 가능하게 정리.
