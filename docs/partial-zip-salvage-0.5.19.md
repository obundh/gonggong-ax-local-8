# 0.5.19 — 손상 문서에서 검증된 텍스트 부분 보존

6단계 F36의 제한적 보강이다. 중앙 목록을 잃은 DOCX/XLSX/PPTX/HWPX에서 뒤쪽 항목 하나가 잘렸거나 선택한 XML 일부가 손상됐을 때, 다른 검증된 텍스트까지 버리던 동작을 바꾼다. 도구 · 안내 → 손상 문서의 부분 내용 추출에서 사용한다.

## 처리와 출력

처음부터 이어지는 로컬 ZIP 항목의 선언된 경계만 따라간다. 구조가 잘린 지점에서는 멈추고 뒤쪽에서 다른 시작 표식을 찾아 붙이지 않는다. 완전히 읽힌 선택 XML은 압축 경계·해제 길이·CRC·지원 XML 구문 검사를 거친다. 개별 CRC·압축·XML 오류는 해당 항목의 미추출 이유로 남기며, 다른 검증된 텍스트가 있으면 별도 `.salvaged.txt`로 보존한다. 검증된 텍스트가 하나도 없으면 결과를 발행하지 않는다.

원시 입력은 덮어쓰지 않는다. 결과에는 추출한 내부 항목 이름과 해시, 빠진 항목 및 이유, 구조 중단 위치·미검사 바이트, 입력과 출력 SHA-256을 남긴다. 텍스트 파일과 화면 모두 일부 내용임을 표시한다. 이 해시는 저장된 자료의 식별 정보이며 삭제 전 원본과의 동일성 증명이 아니다.

입력 최대 64MiB, 완전히 읽은 ZIP 항목 최대 512개, XML 시도 최대 32개, XML 해제 크기 합계 최대 64MiB다. 한도를 넘은 선택 항목은 미추출로 표시한다. 암호화·데이터 디스크립터·ZIP64 크기·미지원 압축/플래그·잘못된 이름·중복 이름·발견된 매크로·외부 엔터티는 계속 거절한다. 미검사 꼬리에 활성 콘텐츠가 없다고 보장하지 않으며, 어떠한 매크로·외부 연결도 실행하지 않는다.

ZIP 로컬 헤더와 CRC 기준은 [PKWARE APPNOTE 6.3.10](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT)의 4.3.7, 4.3.9, 4.1.5를 참고했다. 외부 구현 코드를 복사하거나 의존성을 추가하지 않았다.

## 한계와 보류

PDF·HWP 본문의 수리, 원래 문서 파일 재생성, 서식·그림·표 관계 복원, 알려지지 않은 경계 뒤의 조각 검색은 이번 범위가 아니다. XLSX 값의 의미 해석이나 PPTX 슬라이드 순서도 보장하지 않으며, 내부 항목별 텍스트를 구분해 제공한다. F36 전체 인수는 미완료이며 필수 기준 **19/54(35.2%)**를 유지한다.

0.5.18 실매체 시험의 실패 35건은 별도 보류한다. 최근 삭제 경로에서 본문 후보가 없던 29건과 저장 후 정답 해시가 달랐던 6건이다. 사후 기록 자리 재사용과 0이 많은 저장본은 관측됐지만, 실패 시점의 정확한 원인·TRIM·물리 소실을 확정하지 않는다. 같은 삭제 사건의 발견/본문 확보 시각과 읽은 구간을 통제한 후속 실험이 필요하다. 이번 변경을 SSD 원본 복구율 상승으로 계산하지 않는다.

## 검증

고정 손상 문서를 구·신 버전에 동일하게 제공하는 비교, 정상 부분과 손상 부분의 분리, 손상 뒤 미탐색, 한도·취소·원본 변경, 실제 작업자와 Electron 결과 표시를 확인한다. 결과 근거는 `E:/RecoveryChat-PartialZip-0519-20260927/acceptance.json`과 같은 폴더의 시험 로그에 보존한다. 합성 문서 텍스트 추출 성공과 실제 SSD 삭제 복구 성공은 별도 지표다.
