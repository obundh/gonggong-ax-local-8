# 측정 방법과 공개 증거

공개 정리일 2026-10-02. 아래는 개발 과정에서 남긴 기록을 정리한 것으로, 이번 게시 작업에서 SSD 삭제 시험을 새로 한 것은 아닙니다. 개인 파일명·본문·원본/복구본·전체 후보 목록·장치 식별자는 공개하지 않습니다.

## 실제 SSD 반복 시험: 0.6.0, 2026-09-27

같은 소유 파일 5개를 매 회 새로 복사한 뒤 휴지통을 거쳐 해당 시험 항목만 제거했습니다. 사용자의 휴지통 전체를 비우지 않았습니다. 실제 C: NTFS SSD의 남은 기록을 외부 Node 시험 도구가 배포 엔진과 native 도우미로 검색했습니다. GUI 클릭으로 수행한 시험은 아닙니다.

검색 입력에 정답 파일명·사전 파일 ID·원본 바이트를 넣지 않았습니다. 검색 후보를 확정한 뒤 시험 정답표로 대상을 선택·채점했습니다. 따라서 일반 사용자의 후보 선택 성공률을 측정한 것도 아닙니다. 기준본은 사후 비교에만 사용했습니다.

| 익명 파일 | 반복 수 | 단서 | 저장 | 원본 크기·SHA-256 일치 |
|---|---:|---:|---:|---:|
| PDF 1개 | 10 | 10 | 0 | 0 |
| HWP 1개 | 10 | 10 | 3 | 1 |
| JPEG 1개 | 10 | 10 | 5 | 3 |
| PNG A 1개 | 10 | 10 | 4 | 2 |
| PNG B 1개 | 10 | 10 | 9 | 6 |
| 합계 | 50 | 50 | 21 | 12 |

회차별 원본 일치 수는 `0, 1, 2, 0, 3, 1, 4, 0, 1, 0`입니다. 50종 파일을 시험한 것이 아니며, 일반적인 성공률로 표현하지 않습니다. 원본 일치 실패 38건은 미저장 29 + 저장했으나 불일치 9입니다. 외부 문서 앱의 정상 열림, 전체 C: 카빙, 실패별 TRIM/물리적 덮어쓰기 확정은 포함하지 않았습니다.

검색 시간 중앙값 약 46.13초, 시험 한 회 전체 약 95.40초였습니다. Node 시험 도구·작업자의 표본 RSS 최대 약 595.11MiB이며 Electron UI·native 도우미와 OS 전체 메모리를 포함하지 않습니다. 특정 시험 조건의 관측값입니다.

- [익명화된 전체 집계 JSON](evidence/ssd-0.6.0-summary.json): 원래 파일명 대신 별칭, 당시 원본 요약 파일의 SHA-256, 시험 범위 포함.
- [PNG 사례 재확인 JSON](evidence/case-png-reverified.json): 3,061,560바이트, 복구 출력·보관 사본·기준본 해시가 2026-09-30 재확인 때 일치. 앱의 `originalIdentityVerified=false`, `applicationOpenVerified=false`와 별도로 시험 채점기가 확인한 바이트 일치입니다.

원본 요약의 해시는 기록 연결용이며, 공개하지 않은 자료를 제3자가 모두 독립 재현했다고 주장하는 근거가 아닙니다. 만화는 이 기록을 재구성한 설명 그림입니다.

## 고정 이미지 재개 시험: 0.6.1, 2026-09-27

256MiB 합성 이미지에 경계 PDF 표식 등을 배치하고 128MiB 검색 후 재실행했습니다. 각 버전 3회, 순서를 번갈아 실행했으며 OS 캐시는 초기화하지 않았습니다. 원본 바이트 일치는 양쪽 매회 5/5였습니다. 최초+재실행 검색 읽기는 402,653,184바이트에서 268,435,463바이트로 약 33% 줄었습니다. 구조·추출·이전 출력 검증 읽기는 별도이며, 실제 장치 속도나 복구율의 측정값이 아닙니다.

- [재개 계측 원자료](evidence/resume-0.6.1-measurement.json)
- [당시 인수 요약](evidence/acceptance-0.6.1-summary.json): 엔진 677 통과/0 실패/2 환경 건너뜀, 통합 8, 저장 1, 배포 GUI 2. GUI 시험은 파일 선택·장치 목록에 시험 입력을 사용했으며 실제 worker/IPC/출력 해시를 확인했습니다.

0.6.1 실제 SSD 삭제 시험은 새로 하지 않았습니다. 새 게시 준비 검사는 [공개본 검증 기록](PUBLICATION.md)으로 분리합니다.

## 공개되지 않은 과거 기록과 재현 제한

기존 기술 문서의 E: 경로는 개발 PC에 남은 당시 증거 식별자입니다. 외부에서 열리는 링크가 아니며, 원시 자료에는 개인 파일·경로가 섞일 수 있어 그대로 배포하지 않습니다. 작은 합성 FAT16 독립 비교는 [범위와 실행 방법](independent-comparison-0.6.0.md)을 제공하지만, NTFS 실매체 일반 성능으로 확대 해석하지 않습니다.

회귀 시험 중 일부가 과거 E: 비교 소스와 Windows 권한에 의존하고, GUI 시험에는 별도 Playwright가 필요합니다. 새 환경 전체 재현은 아직 인수하지 않았습니다. 이식성을 보강하는 일도 남은 과제로 공개합니다.
