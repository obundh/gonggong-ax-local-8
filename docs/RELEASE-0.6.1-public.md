# 0.6.1 공개 시험판 — 2026-10-02

Windows 파일 복구 기술 시제품을 처음 공개합니다. **완성된 전문 포렌식 제품이나 완전 복구를 보장하는 도구가 아닙니다.**

이번 공개는 기존 0.6.1 런타임, 기술 기록, 익명화 시험 결과와 고양이 만화 3장으로 구성합니다. 2026-09-27 로컬 배포본의 런타임 파일은 유지하고, 공개 문서에서 개인 파일명을 지우며 현재 진행상황과 한계를 추가했습니다. 새 복구 알고리즘이나 새 SSD 복구율 측정으로 발표하지 않습니다.

- 필수 인수 **21/54**, 필수 보류 **33개**. 조건부 연구 **0/6**. 10단계 검토와 모든 기능 완성은 다릅니다.
- 실제 SSD 시험은 **0.6.0 / 같은 파일 5개 × 10회**. 단서 **50/50**, 본문 저장 **21/50**, 원본 크기·SHA-256 일치 **12/50**. 일반 복구율이 아니며, 외부 시험 정답표로 후보 고정 후 선택·채점했습니다.
- 0.6.1의 추가 검증은 **변경되지 않은 디스크 이미지의 정밀 검색 재개**입니다. 실제 볼륨 재개나 실제 SSD 복구율 향상은 검증하지 않았습니다.
- 발견·저장·원본 일치·문서 정상 열림은 별개입니다. 미리보기나 저장 성공을 완전 복구로 세지 않습니다.
- 원본 장치와 다른 물리 디스크에 앱 작업 공간과 복구 출력 폴더를 두세요. ZIP 전체를 풀어 EXE를 실행해야 합니다. 코드 서명·모든 장치 호환성을 갖춘 정식 배포가 아닙니다.
